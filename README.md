# 職業人生ゲーム

子ども向け職業体験イベント「職業人生ゲーム」の紹介サイトです。吹田産業フェアに向けて作り直しています。

## ページ構成

- `index.html` — トップ（メインビジュアル／地域を選ぶ／各ページへの入口／ニュース）
- `about.html` — 職業人生ゲームとは（想い・理念、遊び方、マスの説明）
- `sponsors.html` — 各地の協賛企業（高槻・吹田をタブで切り替え。`sponsors.html#suita` で吹田を直接表示）
- `organizer.html` — 主催団体（AporTar）
- `support.html` — 賛助企業（MTK）
- `faq.html` — よくある質問
- `contact.html` — お問い合わせ・協賛のご案内
- `style.css` — 全ページ共通のスタイル
- `script.js` — 全ページ共通のヘッダー・フッター、スライド、タブなど

ヘッダー・フッターのリンクや Instagram のURLは `script.js` の先頭でまとめて変更できます。

## 仮のままの部分

「仮」「準備中」と表示している箇所は、素材が届いたら差し替えます。

- ロゴ（今は 🎲 と文字）
- メインビジュアルの写真（今は企画書にある職業カードの写真を仮で使用。`.hero-slide` を増やすと自動でスライド）
- 協賛企業のロゴと紹介文
- AporTar・MTK の紹介文
- Instagram のURLと最新投稿の埋め込み
- 問い合わせフォームの送信先

## 確認方法

`index.html` をブラウザで開くだけで表示できます。
