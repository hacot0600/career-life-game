はじめに一度だけ設定します

保存するとGitHubのサイトに直接反映されます。そのための「合言葉（トークン）」を一度だけ入れてください。この合言葉は、このブラウザの中だけに保存されます。

  1. GitHubのトークン作成ページを開く
  2. Token name に「HP編集」、Expiration は好きな期限を選ぶ
  3. Repository access で「Only select repositories」を選び、career-life-game を選ぶ
  4. Permissions の Repository permissions で Contents を「Read and write」にする
  5. 一番下の「Generate token」を押し、表示された github_pat_ から始まる文字をコピーする
